# Gear Works

**Gear Works** is a free, creativity-driven JavaScript programming and learning platform designed primarily for middle and high school students.

Inspired by tools such as MIT's Scratch, Gear Works is intended to help students transition from beginner-friendly programming environments into writing real code. It combines a browser-based code editor, project system, tutorials, documentation, customizable assets, and an extension system into one platform.

**Website:** https://gearworks.org
**Source:** https://github.com/hiruevan/gearworks

---

## Features

### 🖥️ Browser-Based Code Editor

Gear Works includes a built-in JavaScript editor powered by the **Ace Editor**.

The editor provides:

* JavaScript syntax highlighting
* Code editing and execution
* Line numbers and configurable text sizes
* An integrated console
* Error and warning reporting
* Documentation access
* Asset management
* Project loading and saving
* Fullscreen support
* Custom editor controls

The goal is to let students focus on writing and experimenting with code without requiring a complicated development environment.

---

### 🎨 Creative Coding

Gear Works is designed around creative programming rather than purely academic exercises.

Students can use JavaScript to create projects involving:

* Canvas graphics
* Images
* Animation
* Sound
* User input
* Game mechanics
* Custom shapes and interfaces
* Interactive experiences

The platform provides a small Gear Works JavaScript library that adds functionality on top of the browser's standard APIs.

For example:

```javascript
gearWorks.log("Hello, Gear Works!");
gearWorks.warn("This is a warning.");
gearWorks.error("Something went wrong.");
```

Projects can also interact with the Gear Works canvas and loaded assets.

## Project System

Gear Works uses its own project format: **`.gw1`**.

A Gear Works project can contain:

* Project metadata
* Project title
* JavaScript source code
* Images
* Sounds
* Extensions

Projects can be loaded directly into the editor from a `.gw1` file.

Example projects are included in the repository under: 

```text

```

Current sample projects include:

## Extensions

Gear Works includes an **Extension Creation Interface (ECI)** that allows developers, students, and teachers to create custom extensions for the editor.

Extensions use the **`.gwx`** format.

An extension can contain:

* Extension name
* Author
* Overview
* Color
* JavaScript code
* Documentation

Extensions effectively act as optional modifications to the Gear Works editor, allowing the platform to be expanded beyond its default functionality.

> Extensions are an experimental feature and are not officially guaranteed to work with every version of Gear Works.
> *Disclaimer: These extensions have not been verified to be completely secure. This may be improved in the future.*

The ECI can be found in the repository at:

```text
docs/eci.html
docs/eci.js
```

## Built-In Gear Works API

Gear Works provides a JavaScript API for projects.

Some of the available functionality includes:

### Console

```javascript
gearWorks.log(message);
gearWorks.warn(message);
gearWorks.error(message);
gearWorks.clear();
```

### Assets

Projects can access assets through the Gear Works asset cabinet.

```javascript
gearWorks.url("/image.png");
gearWorks.playSound("/sound.wav");
```

### Canvas

The Gear Works environment provides access to the project canvas and additional drawing functionality.

```javascript
draw.image("/player.png", 100, 100);
```

The library also provides utilities such as canvas resizing and rounded-corner configuration.

For the complete API, see the developer documentation included with the project.

## Technology

Gear Works is primarily a client-side web application.

### Frontend

* HTML
* CSS
* JavaScript
* Canvas API
* Ace Editor
* jQuery

### Local Development Server

The repository includes a lightweight **FastAPI** server in `main.py`.

The server:

* Serves the Gear Works website
* Serves static files from the repository directory
* Serves `index.html` at the root
* Supports extensionless HTML routes
* Provides a convenient local development environment
* Prints both localhost and local-network addresses when started

## Running Locally

### Requirements

You will need:

* Python 3
* FastAPI
* Uvicorn

Install the Python dependencies with:

```bash
pip install fastapi uvicorn
```

### Start the Server

From the root of the repository, run:

```bash
python main.py
```

The server will start on port `8000`.

You should see output similar to:

```text
Server running at:
  Local:   http://127.0.0.1:8000
  Network: http://YOUR_LOCAL_IP:8000

Press CTRL+C to stop the server.
```

Open the local address in a browser:

```text
http://127.0.0.1:8000
```

## Development

Gear Works is structured as a relatively lightweight web application. Most of the platform's behavior is implemented directly in JavaScript and can be explored through the files in:

```text
editor/
loaders/
docs/
```

The editor's internal functions generally use the `gw_` prefix to reduce naming conflicts with user code.

Examples include:

```javascript
gw_toggleSideBar();
gw_switchToDocs();
gw_switchToConsole();
gw_toggleFileBox();
gw_openProject();
```

The Gear Works runtime API exposed to student projects uses the `gearWorks` object.
